Company logos for the home page, /buyers and buyer pages.

logos.json maps each file here to the phrases that name that buyer. A buyer
whose name contains one of the phrases (any case, whole words) shows that
file; the longest matching phrase wins. A buyer with no match keeps its
two-letter tile. To add one: drop the file here and add a line to logos.json.
Files are read when the server starts, so restart (or redeploy) afterwards.

Where these came from: Wikimedia Commons (via Wikidata) and the infobox logo
of each organisation's English Wikipedia article, fetched 2026-10-10. They
are used only to identify the buyer next to its own tenders.

Ministries show the State Emblem of India (emblem.png) and the armed forces
their flags and crests. Note that the State Emblem of India (Prohibition of
Improper Use) Act, 2005 restricts using the emblem on a commercial site.
